
Semi AI — Product Requirements Document (PRD)
1. Product Overview
Semi AI is an AI-powered executive assistant designed to help individuals get work done through reliable research, task management, email management, scheduling, document analysis, and intelligent automation.
Semi AI is designed to be more than a chatbot. It should act as a practical virtual assistant that can research information, provide solutions, organize work, and perform authorized tasks.
2. Vision
To build a trusted AI executive assistant that helps people accomplish more by combining verified information, intelligent research, productivity tools, and proactive assistance in one application.
3. Core Principles
No guesswork: Semi AI should not knowingly provide unverified information as fact.
Verify before answering: When appropriate, Semi AI should check reliable web sources, documents, and notes before answering.
Research first: Important questions should be supported by reliable sources.
Proactive assistance: Semi AI should anticipate useful actions and reminders.
User control: Sensitive actions require user confirmation unless the user has explicitly enabled an appropriate automation.
Transparency: Semi AI should explain important corrections and actions.
Privacy: User data must be protected and users must control their stored information.
4. Version 1 Primary Users
Version 1 is focused primarily on individual users.
Team and business collaboration will be introduced in a later version.
5. Version 1 Core Features
5.1 AI Research Assistant
Answer questions and provide solutions.
Search reliable sources on the web.
Check relevant user documents and notes.
Provide a concise summary first.
Allow users to expand the answer for more detail.
Cite relevant sources where available.
Clearly communicate when reliable information cannot be established.
5.2 Task Management
Create tasks.
View tasks.
Update tasks.
Delete tasks with confirmation.
Rank tasks by urgency and importance.
Track task status.
Maintain task history.
Notify users when tasks are completed.
Learn task-related habits over time with user permission.
5.3 Email Management
Connect supported email accounts.
View and summarize emails.
Automatically identify email priority.
Draft replies.
Create follow-up tasks.
Archive emails.
Require confirmation before sending emails.
Require confirmation before deleting email information.
Notify users about important or unread emails.
5.4 Calendar and Scheduling
Schedule appointments.
Track upcoming events.
View daily and weekly schedules.
Create reminders.
Reschedule appointments.
Notify users about upcoming events.
Continue reminders for important events until addressed or dismissed.
5.5 Voice and Text
Semi AI must support both:
Text requests.
Voice commands.
Both should be available from Version 1.
5.6 Memory
With user permission, Semi AI should be able to remember:
User name.
Recurring tasks.
Important preferences.
Relevant email context.
Past discussions.
Projects and routines.
Upcoming events.
Users must have control over what Semi AI remembers.
5.7 Notifications
Semi AI should provide:
Push notifications.
Notification indicators/dots.
Email notifications where appropriate.
Formal notification language.
Persistent reminders for important tasks and unread emails.
5.8 Offline Support
Basic functionality should remain available offline, including:
Viewing tasks.
Creating and updating tasks.
Viewing saved information and summaries.
Drafting email responses.
Changes should synchronize when the device reconnects to the internet.
6. Intelligent Request Routing
When Semi AI receives a request, it should automatically determine whether the request requires:
Research mode.
Executive assistant mode.
Document analysis.
Task execution.
Email assistance.
Scheduling assistance.
Semi AI should begin processing normal requests without waiting for confirmation.
Confirmation should only be required for sensitive actions such as sending emails, deleting information, or other actions designated as high-risk.
7. Task Execution
Semi AI should process multiple requested tasks sequentially, rather than confusingly executing everything at once.
The user should receive progress information and a notification when each task is completed.
8. Self-Correction
If Semi AI discovers that information it provided was incorrect or outdated, it should:
Correct the information.
Notify the user.
Clearly explain that a correction was made.
9. Integrations
Planned integrations include:
Priority
Google Workspace.
Microsoft 365.
Trello.
ClickUp.
Future
LinkedIn.
Upwork.
Instagram.
Additional productivity and communication platforms.
Users should be able to control permissions and disconnect integrations.
10. Custom Automations
Semi AI should eventually support user-defined workflows.
Example:
When I receive an email from a specific client, summarize it, create a follow-up task, and remind me in 24 hours.
Automations involving sensitive external actions must respect the user's permission settings.
11. Security and Privacy
Semi AI should include:
Secure authentication.
Encryption of user data.
User-controlled memory.
Data export.
Permanent data deletion.
Integration permission controls.
Confirmation for sensitive actions.
12. Home Dashboard
The home screen should contain:
Personalized greeting.
Email summary card.
Immediate/high-priority task card.
Large request area for text and voice.
Notification indicator.
The interface should use Semi AI's primary visual identity of gold with touches of blue.
13. Onboarding
New users should be able to:
Create an account.
Provide their name.
Provide email address.
Provide phone number.
Create a password.
Verify their email.
Set preferences.
Connect integrations.
Receive a short introduction to Semi AI.
The introduction should contain three visual slides explaining the product.
14. Product Personality
Semi AI should be:
Proactive.
Professional.
Reliable.
Clear.
Helpful.
Formal when sending notifications.
Honest when information cannot be verified.
15. What Semi AI Is Not
Semi AI is not primarily an image-generation application.
Its primary purpose is research, productivity, task execution, communication, and intelligent assistance.
16. Version 1 Pricing
Semi AI will initially launch with a free version to encourage adoption and gather user feedback.
Paid plans such as Pro and Business can be introduced in a future release.
17. Future Roadmap
Future versions may include:
Team collaboration.
Business accounts.
Advanced workflow automation.
More integrations.
Expanded social-media management.
Advanced AI capabilities.
Paid subscription plans.
Additional platforms.
18. Design Direction
Primary brand colors:
Gold — intelligence, value, premium quality.
Blue — trust, reliability, technology.
The design should be modern, clean, professional, and easy to use.
Visual illustrations should reinforce Semi AI's identity as a trusted research and executive assistant rather than an entertainment chatbot.
19. Success Principle
The central question behind every Semi AI feature should be:
"Does this help the user get something important done, reliably and efficiently?"
If the answer is no, the feature should not be a priority.
